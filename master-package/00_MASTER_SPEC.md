# Conductor - AI Agent Orchestration SaaS
## Complete Master Specification (2026)

### 1. 製品ビジョン（絶対にブレさせない）

Conductorは「一人の人間が、複数のAIエージェントを正確に指揮するための司令塔」である。

- 目的はエージェントを賢くすることではない。
- 目的は「人間がエージェントチームを信頼して指揮できる状態」を作ることである。
- 核心価値は以下の4点のみ：
  1. 役割と権限の明確な設定
  2. リアルタイムでの完全な可視化（監視）
  3. 意図的でストレスの少ないエスカレーション（Human-in-the-loop）
  4. 指揮している実感（Command & Control体験）

イーロン・マスク的世界観（労働価値の相対的低下 → 生産手段を持つ側の価値向上）を個人レベルで体現するツール。

### 2. ターゲット
個人開発者、フリーランス、一人会社（1-5人）。エンタープライズ複雑さは排除。

### 3. 技術スタック（厳守）
- Next.js 15 (App Router) + TypeScript + Tailwind + shadcn/ui
- Supabase (Auth + Postgres + Realtime)
- Inngest（バックグラウンドジョブ）
- LangGraph（エージェント実行層を薄くラップ）
- Stripe（課金）
- Vercel（デプロイ）

### 4. 核心画面
1. ダッシュボード（状態が一目でわかる）
2. エージェント詳細（3カラム）
3. エスカレーション画面（最重要・認知負荷最小）
4. テンプレート起動画面
5. 新規エージェント作成
6. 設定

### 5. 核心ユーザーフロー
テンプレート起動 → エージェント自動稼働 → リアルタイム監視 → エスカレーション発生 → 人間回答 → 再開 → 完了

### 6. 価格
- Free: $0（エージェント2体・制限付き）
- Starter: $29
- Pro: $79
- Scale: $149+

### 7. 実装原則
- Phase順を厳守
- エスカレーションの完成度を最優先
- UIはLinear / Vercel / Raycast級を目指す
- 自分でResearch Crewを毎日回してドッグフーディングする

この仕様がすべての判断の最終根拠である。
