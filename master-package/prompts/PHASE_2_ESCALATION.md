# Phase 2: Escalation System (最重要)

エスカレーションはConductorの核心です。ここを世界最高品質で実装してください。

必須：
1. エスカレーション画面UI
   - 最上部に大きな「状況の要約」
   - 折りたたみ可能な経緯
   - 選択肢ボタン + 自由記述
   - 「承認して続行」「修正して指示」「中止」
2. 回答API（status更新 + human_response保存）
3. 回答後にエージェントを再開する仕組み（Inngest推奨）
4. ダッシュボードから「要対応」への強い導線
5. Realtimeでエスカレーション発生を即時検知

認知負荷を最小限にすること。人間が「今何を判断すればいいか」を3秒で理解できる設計を厳守。
