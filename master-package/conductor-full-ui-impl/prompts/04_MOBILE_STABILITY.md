# 04. モバイル安定感の実装

対象: 全体（特に AppShell 下部タブ、Needs You、Dashboard、公開面）

## 目的
どの画面でも親指操作がストレスなく、レイアウトが崩れない状態にする。

## 必須対応

1. **Safe Area**
   - 下部タブに `pb-safe` または `safe-area-pb` を適用
   - 固定ボタン（Escalation の Approve など）もホームインジケーターと被らないようにする

2. **タッチターゲット**
   - すべての主要なボタン・選択肢の高さは最低 44–48px
   - Needs You の選択肢は特に指で押しやすいサイズに

3. **下部タブとコンテンツの干渉防止**
   - メインコンテンツの `padding-bottom` をタブの高さ分確保
   - スクロール時にタブがコンテンツを隠さない

4. **横幅の安定**
   - 小さい画面で文字がはみ出さないよう `truncate` / `line-clamp` を適切に使用
   - カードや選択肢が画面幅いっぱいに使いやすいこと

5. **公開面（Landing / Demo / Moment）**
   - モバイル縦積み時の余白を十分に取る
   - 主CTAボタンの高さを確保

## 完了条件
- iPhone サイズでも下部タブとコンテンツが被らない
- Needs You の選択肢が親指で楽に押せる
- 横向き・小さい画面でも致命的な崩れがない
