# Cursor Prompt: EscalationDecision 最終磨き

`src/components/escalation/EscalationDecision.tsx` を世界最高水準に調整してください。

## 現状の良い点（維持）
- 状況の要約が最上部にある
- 選択肢 + 自由記述
- キーボードショートカット（A / R / Esc）
- 回答後の状態更新

## 追加・強化する点

1. **選択状態の明確化**
   - 選択肢をクリックした瞬間に背景が反転し、選択中であることが一目でわかる
   - 番号を大きく見やすく

2. **ショートカットの発見可能性**
   - 画面下部または各ボタンの近くに `A` `R` `Esc` を常時小さく表示
   - 「Keyboard」ヒントを初回だけ出してもよい

3. **回答後の体験**
   - 送信直後に「Resuming agent…」のフィードバックを明確に
   - 成功後は Dashboard または該当エージェント詳細へスムーズに戻る
   - toast で「Decision recorded」を出す

4. **視覚的優先度**
   - 「NEEDS YOU」バーをさらに強く（色・サイズ・位置）
   - 他の装飾を削ぎ落とし、判断に集中させる

5. **モバイル**
   - 下部の固定アクションバーが親指で押しやすい位置にあること
   - 選択肢が画面幅いっぱいに使いやすいこと

## 禁止
- 既存の submit ロジック（approve / revise / cancel）を壊さない
- API の契約を変えない

完了条件:
- 選択肢の選択状態が明確
- ショートカットが発見しやすい
- モバイルでもストレスなく判断できる
