# Cursor Prompt: Dashboard を「指揮台」に再設計

`src/components/dashboard/DashboardView.tsx`（および関連）を以下の仕様で刷新してください。

## 目標
3秒で「全体の状況」がわかり、必要な介入に1クリックで到達できる指揮台にする。

## レイアウト構造

```
┌──────────────────────────────────────────────────────────┐
│  Status strip（Running / Needs You / Completed の数字）   │
│  Needs You がある場合は赤い強調バーを最上部に出す         │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  エージェントカードグリッド（ドラッグ並び替え可能）       │
│  - waiting_human のカードを視覚的に最も強く               │
│  - カードクリックで詳細へ                                 │
│                                                          │
├──────────────────────────────────────────────────────────┤
│  下段: 最近のエスカレーション or 最近の Results への導線  │
└──────────────────────────────────────────────────────────┘
```

## 必須機能

1. **Needs You 強調**
   - 未対応エスカレーションが1件以上ある場合、画面上部に赤いコマンドバーを表示
   - 「Decide」ボタンで該当エスカレーションへ直接遷移

2. **カードのドラッグ並び替え**
   - `@dnd-kit` または既存の軽い実装で順序変更
   - 順序は localStorage に保存（キー: `conductor-agent-order`）
   - ページリロード後も順序が維持される

3. **空状態**
   - エージェントが0のときは「Launch a template」を大きく出す
   - Templates への明確なCTA

4. **主CTA**
   - 画面内の主CTAは原則1つ（Launch または Resolve）

## UIディテール
- カードの余白・角丸・影を統一
- status バッジは既存の AgentStatusBadge を活用しつつ、waiting_human は pulse を維持
- 情報密度は Comfortable を基本に（詰め込みすぎない）

## 禁止
- データ取得ロジック（useAgents など）を壊さない
- 新しいAPIを作らない
- Demo Mode の動作を変えない

完了条件:
- Needs You があるときに赤いバーが確実に出る
- カードをドラッグして順序が保存される
- モバイルでも破綻しない
